Scalp Trends

For each patient
	- Select P15 Trends (F:\Definition_of_Trends)
	- Process a short segmnt of the first laydat record, pause trend processing to save time (after about 10 seconds)
	- Create new panel with the name:
		ScalpSleepStages
	- Add trend Sleep-Wake Stage (pick last one from the list)
	- Save the mmx file generated for this first EEG file (F:\Definition_of_Trends)
	- Clear all processed trends
	- Load the mmx file containing the ScalpSleepStages panel (Preferences -> Trend Prefernces -> Open) 
	- Process first laydat record using mmx containing the ScalpSleepStages panel
	- Once the first laydat record is processed, use the "PersystControlTestCSharpSample.exe" tool to batch process the remaining files
	- Use shell script to export sleep stages as csv



iEEG Spike Detection

- Set to 1 this created Registry Key: HKEY_Current_User->Software->Persyst->PSMMaker->StartStopReveal
- Delete SD4 files containing scalp Spikes
- Delete all files (e.g. scalp trends, scalp spike detections)that are not laydat or csv
- Check which channels are noisy
- Generate Referential montage and exclude noisy channels
- Use created mmx files as intracranial trends file (Prefernces->TrendPreferences->Open-> created mmx file)

- Start Reveal and Pause if it has started
- disable Reveal Autostart and Save Settings (File->AutoStart->Save Auto), otherwise the the autostart will not allow changing the protocol
- Close and clear trends again
- Open Reveal agan, disable Reveal Autostart and Save Settings (File->AutoStart->Save Auto), otherwise the the autostart will not allow changing the protocol 
- Set Protocol so that the correct channels are selected (Referential Montage, exclude noisy, Scalp and non-EEG Channels)
- Save protocol
- Enable Autostart again and Save Settings
- Close Reveal
- Press Process to run the intracranial Trends and Reveal
- Batch process the rest of the records
